# Fashion Book preview

This is a separate, non-indexed preview for a future `model.samuelokotako.com` Cloudflare Pages project. It is not copied into the Data & AI portfolio's `public/` output and has no link from that site's navigation or sitemap.

Publish this folder as a separate Pages project only after the owner confirms the subdomain, current professional details, and rights for every photograph. The four gallery cards are conceptual placeholders, not examples of completed work. No private gallery is implemented: `noindex` and `X-Robots-Tag` do not restrict access. Put any restricted gallery behind authenticated access before uploading private media.

The fonts are local copies from the portfolio with SIL OFL licenses included. A separate Pages deployment should use this folder as its output directory and preserve `_headers` and `robots.txt`. DNS is not configured by this source package.
