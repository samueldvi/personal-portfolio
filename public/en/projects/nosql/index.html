Data Engineering · ITS group project

Airbnb Data Analysis with Databricks

Inside Airbnb data for Amsterdam and Rio de Janeiro organized into Bronze, Silver and Gold layers for analysis.

Explore the architecture ↓

Context

A group Data Engineering project developed during the ITS programme, using Databricks and Inside Airbnb data for Amsterdam and Rio de Janeiro.

Problem

Organize listings and reviews from two cities while separating ingestion, transformation and analytical queries.

Goal

Structure the data in Bronze, Silver and Gold layers to support analysis and comparisons between the two cities.

My responsibilities

I led the team and focused mainly on data ingestion, helping structure the Bronze layer. The Silver transformations, Gold queries and visualizations are presented as group work.

Architecture

Documented implementation

The Bronze notebook sets up ingestion from four detailed listings and reviews CSVs in a Databricks volume, adds city and ingestion timestamp, and includes definitions for four Delta tables. The Silver notebook brings Amsterdam and Rio listings into silver_listings with UNION ALL and converts selected types and prices. Gold contains SQL views and analytical queries; an export preserves two chart configurations.

Technical decisions and tradeoffs

  • CSV ingestion

    Bronze reads fields as strings and configures multiline input, quotes, escaping and PERMISSIVE mode for complex text. The project documentation explains the choice of detailed datasets to retain ratings.

  • Layer separation

    Silver combines listings with UNION ALL and prepares fields for analysis. Listing deduplication is outside the documented transformations.

  • City-specific comparisons

    Amsterdam and Rio use different currencies, so prices need to be compared within each city. Some Gold queries need a city filter to follow that rule.

Technical checks

The code review covers Bronze definitions, silver_listings, Gold views and two chart configurations. Some queries need correction before a new run.

Project materials

  • Source notebooks

    The Bronze ingestion flow, silver_listings transformation and Gold analytical views and queries are documented.

  • Visualizations

    The export retains settings for two charts, one by city and one by accommodation type.

Scope and next steps

This case presents the architecture defined in the notebooks. Reproducing the flow requires completing silver_reviews and correcting some Gold queries; quantitative results from a complete run are not documented.
